# Real Estate Management System

Aplicación web desarrollada con ASP.NET Core siguiendo el patrón MVC para la administración de una inmobiliaria.

## Funcionalidades

- Gestión de propiedades
- Gestión de propietarios
- Gestión de inquilinos
- Administración de contratos
- Registro de pagos
- Autenticación de usuarios
- Operaciones CRUD completas

## Tecnologías

- ASP.NET Core MVC
- C#
- Entity Framework Core
- SQL Server
- Bootstrap
- jQuery
- HTML5
- CSS3

## Arquitectura

El proyecto sigue el patrón MVC utilizando Entity Framework Core como capa de acceso a datos y separación entre lógica de negocio, presentación y persistencia.
